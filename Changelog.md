# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-04-19

### Added
- Initial release of Visual Controller for Preact
- Methods: `publish`, `getApp`, `destroy`, `has`
- Support for dependencies injection
- Support for setupUpdates for external component manipulation
- Support for SSR/hydration
- JSDoc documentation
- Test suite with vitest
